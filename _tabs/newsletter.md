JustMao 週報是每週一封的電子郵件，列出 justmao.com 上週發表的每篇新文章，附上標題、連結與摘要。

信裡的文章多半屬於這幾類：

- **Coding agent 的 skill 與工作流程。** 拿 skill 套件實際跑一遍，從釐清需求走到審查與合併。
- **Agent 帶來的資安問題。** 檢查第三方 skill 與 MCP 拿到哪些權限，也從公開資料還原攻擊鏈。
- **開源工具的原始碼拆解。** 讀特定版本的原始碼，看工具實際做了什麼。

上週沒有新文章的話，那一週就不寄信。
