JustMao 周报是每周一封的电子邮件，列出 justmao.com 上周发表的每篇新文章，附上标题、链接与摘要。

邮件里的文章大多属于这几类：

- **Coding agent 的 skill 与工作流程。** 拿 skill 套件实际跑一遍，从厘清需求走到审查与合并。
- **Agent 带来的信息安全问题。** 检查第三方 skill 与 MCP 拿到哪些权限，也从公开资料还原攻击链。
- **开源工具的源代码拆解。** 读特定版本的源代码，看工具实际做了什么。

上周没有新文章的话，那一周就不发邮件。
