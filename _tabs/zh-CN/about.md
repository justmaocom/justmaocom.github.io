我是软件工程师，一路从信息安全研究、Android 与 Flutter 做到后端，现在工作上大多在处理 AI/LLM 平台、RAG 和 Agent。

AI 让代码写得更快，但需求有没有问清楚、修改有没有弄坏别处、agent 该拿到多少权限，仍然要有人回答。我在这里写的文章，大多在厘清哪些事可以放心交给 AI，哪些仍要由人把关。比起展示能跑，我更在意系统过一阵子还能不能好好维护，以及下一个接手的人看不看得懂。

## 这里写什么

- **Coding agent 的 skill 与工作流程。** 我会实际操作 skill 套件，用具体的例子走过厘清需求、设计、实现、审查与合并各个阶段。[mattpocock/skills](/posts/mattpocock-skills-series-guide/) 与 [pstack](/posts/pstack-series-guide/) 两个系列各有一篇导读，可以从那里挑起点。也会写怎么自己写 Agent Skill，以及怎么把 AI 原生的开发流程缩小到个人项目。
- **Agent 带来的信息安全问题。** 包括第三方 skill 与 MCP 带进来的供应链和权限风险，以及从公开证据还原的攻击链。这类文章会追查工具连到哪些服务、拿到哪些权限，并附上可以照着检查的清单。
- **开源工具的源代码拆解。** 对照特定版本的源代码，确认工具实际做到哪里，和它宣称的差在哪里。
- 另外还有技术演讲的笔记，以及自己动手做的[小项目](/projects/)。

每篇文章多半从一个具体的问题开始。我会附上原始资料、尽量注明查证时的版本，并把查得到的事实和自己的判断分开写，也交代这些判断适用到哪里。
