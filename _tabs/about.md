我是軟體工程師，一路從資安研究、Android 與 Flutter 做到後端，現在工作上大多在處理 AI/LLM 平台、RAG 和 Agent。

AI 讓程式寫得更快，但需求有沒有問清楚、修改有沒有弄壞別處、agent 該拿到多少權限，仍然要有人回答。我在這裡寫的文章，大多在釐清哪些事可以放心交給 AI，哪些仍要由人把關。比起展示能跑，我更在意系統過一陣子還能不能好好維護，以及下一個接手的人看不看得懂。

## 這裡寫什麼

- **Coding agent 的 skill 與工作流程。** 我會實際操作 skill 套件，用具體的例子走過釐清需求、設計、實作、審查與合併各個階段。[mattpocock/skills](/posts/mattpocock-skills-series-guide/) 與 [pstack](/posts/pstack-series-guide/) 兩個系列各有一篇導讀，可以從那裡挑起點。也會寫怎麼自己寫 Agent Skill，以及怎麼把 AI 原生的開發流程縮小到個人專案。
- **Agent 帶來的資安問題。** 包括第三方 skill 與 MCP 帶進來的供應鏈和權限風險，以及從公開證據還原的攻擊鏈。這類文章會追查工具連到哪些服務、拿到哪些權限，並附上可以照著檢查的清單。
- **開源工具的原始碼拆解。** 對照特定版本的原始碼，確認工具實際做到哪裡，和它宣稱的差在哪裡。
- 另外還有技術演講的筆記，以及自己動手做的[小專案](/projects/)。

每篇文章多半從一個具體的問題開始。我會附上原始資料、盡量註明查證時的版本，並把查得到的事實和自己的判斷分開寫，也交代這些判斷適用到哪裡。
